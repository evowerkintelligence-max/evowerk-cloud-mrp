# Machine / Work Center / Routing Master Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give this app a real shop-floor asset registry (`WorkCenter`, `Machine`, `Routing`, `RoutingStep`) and retrofit the three existing free-text machine/line columns (`DowntimeIncident.machine`, `MaintenanceSchedule.machine`, `PaceSession.line`) onto real foreign keys into it.

**Architecture:** Four new `org_id`-scoped tables following the existing `Location`/`Bom` conventions (manual Alembic migrations, manual Pydantic request/response mapping, `require_role("owner")` + `log_event` on mutations). A shared name-matching helper (exact-match-or-flag-fuzzy) is used both by a one-time backfill script and by `MaintenanceSchedule`'s programmatic creation path; `DowntimeIncident`/`PaceSession` retrofit to explicit dropdown selection instead, since those already have a human filling in a form.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 (async), Alembic, pytest + pytest-asyncio + httpx (backend); React + TanStack Query + React Router (frontend). No new dependencies — the fuzzy-match step uses a small stdlib-only Levenshtein implementation, not a new library.

## Global Constraints

- Every new table is `org_id`-scoped with `ForeignKey("orgs.id", ondelete="CASCADE")`, indexed.
- No hard `DELETE` route on `WorkCenter`/`Machine`/`Routing` once referenced elsewhere — only status transitions (mirrors the rest of this schema's orphan-avoidance pattern).
- Migrations are hand-written (not autogenerated) and chain from the current head, `a2f7c5e91d84` (shift schedules, not a secret — an Alembic revision id) — generate each with `alembic revision -m "<name>"` so Alembic sets `down_revision` correctly to whatever the head is at that point, then fill in `upgrade()`/`downgrade()`.  <!-- pragma: allowlist secret -->
- New model modules must be added to **both** `backend/alembic/env.py`'s and `backend/tests/conftest.py`'s `# noqa: F401 - register models` import lists, or Alembic/tests silently won't see the new tables.
- Duplicate `code` within an org → `409` via the existing `IntegrityError` catch pattern (see `locations.py`).
- Mutating routes: `Depends(require_role("owner"))`; reads: `Depends(get_current_user)`.

from __future__ import annotations

import uuid
from datetime import datetime, timezone

from sqlalchemy import DateTime, Float, ForeignKey, Integer, String, UniqueConstraint, Uuid
from sqlalchemy.orm import Mapped, mapped_column

from app.db.base import Base


class WorkCenter(Base):
    """A routing step type (e.g. "CNC Milling") - the physical/logical station
    a Routing's steps point at. Distinct from Machine: a work center can have
    several interchangeable Machines (machine_capacity), so one broken
    machine doesn't take the whole station down for simulation/queueing
    purposes."""

    __tablename__ = "work_centers"
    __table_args__ = (UniqueConstraint("org_id", "code", name="uq_work_centers_org_code"),)

    id: Mapped[uuid.UUID] = mapped_column(Uuid(as_uuid=True), primary_key=True, default=uuid.uuid4)
    org_id: Mapped[uuid.UUID] = mapped_column(
        Uuid(as_uuid=True), ForeignKey("orgs.id", ondelete="CASCADE"), nullable=False, index=True
    )
    code: Mapped[str] = mapped_column(String(50), nullable=False)
    name: Mapped[str] = mapped_column(String(255), nullable=False)
    # active | inactive | retired - not an enum column so a new status later
    # doesn't need a migration, validated in the route instead (matches Item.item_type).
    status: Mapped[str] = mapped_column(String(16), nullable=False, default="active")
    machine_capacity: Mapped[int] = mapped_column(Integer, nullable=False, default=1)
    default_cycle_time_seconds: Mapped[float | None] = mapped_column(Float, nullable=True)
    default_mtbf_hours: Mapped[float | None] = mapped_column(Float, nullable=True)
    default_mttr_hours: Mapped[float | None] = mapped_column(Float, nullable=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=lambda: datetime.now(timezone.utc)

# backend/app/api/routes/work_centers.py
from __future__ import annotations

import uuid
from typing import Any

from fastapi import APIRouter, Depends, HTTPException, status
from pydantic import BaseModel
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from app.api.deps import CurrentUser, get_current_user, get_or_404, require_role
from app.db.session import get_db
from app.middleware.audit import log_event
from app.models.work_center import WorkCenter

router = APIRouter(prefix="/work-centers", tags=["work-centers"])

_STATUSES = {"active", "inactive", "retired"}


class WorkCenterCreateRequest(BaseModel):
    code: str
    name: str
    machine_capacity: int = 1
    default_cycle_time_seconds: float | None = None
    default_mtbf_hours: float | None = None
    default_mttr_hours: float | None = None


class WorkCenterUpdateRequest(BaseModel):
    name: str | None = None
    status: str | None = None
    machine_capacity: int | None = None
    default_cycle_time_seconds: float | None = None
    default_mtbf_hours: float | None = None
    default_mttr_hours: float | None = None


class WorkCenterResponse(BaseModel):
    id: str
    code: str
    name: str
    status: str
    machine_capacity: int
    default_cycle_time_seconds: float | None
    default_mtbf_hours: float | None
    default_mttr_hours: float | None


def _to_response(wc: WorkCenter) -> WorkCenterResponse:
    return WorkCenterResponse(
        id=str(wc.id),
        code=wc.code,
        name=wc.name,
        status=wc.status,
        machine_capacity=wc.machine_capacity,
        default_cycle_time_seconds=wc.default_cycle_time_seconds,
        default_mtbf_hours=wc.default_mtbf_hours,
        default_mttr_hours=wc.default_mttr_hours,
    )


@router.get("", response_model=list[WorkCenterResponse])
async def list_work_centers(
    current: CurrentUser = Depends(get_current_user),
    db: AsyncSession = Depends(get_db),
):
    result = await db.execute(
        select(WorkCenter).where(WorkCenter.org_id == current.org_id).order_by(WorkCenter.code)
    )
    return [_to_response(wc) for wc in result.scalars().all()]


@router.post("", response_model=WorkCenterResponse, status_code=status.HTTP_201_CREATED)
async def create_work_center(
    body: WorkCenterCreateRequest,
    current: CurrentUser = Depends(require_role("owner")),
    db: AsyncSession = Depends(get_db),
):
    if body.machine_capacity < 1:
        raise HTTPException(status.HTTP_400_BAD_REQUEST, "machine_capacity must be at least 1")
    wc = WorkCenter(
        org_id=current.org_id,
        code=body.code,
        name=body.name,
        machine_capacity=body.machine_capacity,
        default_cycle_time_seconds=body.default_cycle_time_seconds,
        default_mtbf_hours=body.default_mtbf_hours,
        default_mttr_hours=body.default_mttr_hours,
    )
    db.add(wc)
    try:
        await db.flush()
    except IntegrityError:
        await db.rollback()
        raise HTTPException(status.HTTP_409_CONFLICT, "code already exists in this org") from None

    await log_event(
        db, action="work_center.created", org_id=current.org_id, actor_user_id=current.id,
        target=str(wc.id), metadata={"code": wc.code},
    )
    await db.commit()
    return _to_response(wc)


@router.patch("/{work_center_id}", response_model=WorkCenterResponse)
async def update_work_center(
    work_center_id: uuid.UUID,
    body: WorkCenterUpdateRequest,
    current: CurrentUser = Depends(require_role("owner")),
    db: AsyncSession = Depends(get_db),
):
    wc = await get_or_404(db, WorkCenter, current.org_id, work_center_id, "Work center not found")
    if body.status is not None and body.status not in _STATUSES:
        raise HTTPException(status.HTTP_400_BAD_REQUEST, f"status must be one of {sorted(_STATUSES)}")
    if body.machine_capacity is not None and body.machine_capacity < 1:
        raise HTTPException(status.HTTP_400_BAD_REQUEST, "machine_capacity must be at least 1")

    fields: dict[str, Any] = body.model_dump(exclude_unset=True)
    for key, value in fields.items():
        setattr(wc, key, value)

    await log_event(
        db, action="work_center.updated", org_id=current.org_id, actor_user_id=current.id,
        target=str(wc.id), metadata=fields,
    )
    await db.commit()
    await db.refresh(wc)
    return _to_response(wc)
```

from __future__ import annotations

import uuid

    return RoutingResponse(
        id=str(routing.id), item_id=str(routing.item_id), version=routing.version, status=routing.status,
        steps=[_step_response(s) for s in steps],

async def replace_routing_steps(
    routing_id: uuid.UUID,
    steps: list[RoutingStepRequest],
    current: CurrentUser = Depends(require_role("owner")),
    db: AsyncSession = Depends(get_db),
):
    routing = await get_or_404(db, Routing, current.org_id, routing_id, "Routing not found")
    if routing.status != "draft":
        raise HTTPException(status.HTTP_409_CONFLICT, "Only draft routings can be edited")
    if not steps:
        raise HTTPException(status.HTTP_400_BAD_REQUEST, "A routing needs at least one step")

    sequences = [s.sequence for s in steps]
    if len(set(sequences)) != len(sequences):
        raise HTTPException(status.HTTP_400_BAD_REQUEST, "Step sequence numbers must be unique")

    for s in steps:
        if await get_or_404(db, WorkCenter, current.org_id, s.work_center_id, "Work center not found") is None:
            pass  # get_or_404 raises internally; unreachable, kept for clarity

    for s in steps:
        db.add(RoutingStep(
            org_id=current.org_id, routing_id=routing.id, sequence=s.sequence,
            work_center_id=s.work_center_id, cycle_time_seconds=s.cycle_time_seconds,
            setup_time_seconds=s.setup_time_seconds,
        ))

    await log_event(
        db, action="routing.steps_replaced", org_id=current.org_id, actor_user_id=current.id,
        target=str(routing.id), metadata={"step_count": len(steps)},
    )
    await db.commit()
    await db.refresh(routing)
    return await _routing_response(db, routing)

"""Shared free-text -> registry-row matching, used by the one-time backfill
script (scripts/backfill_machine_registry.py) and by MaintenanceSchedule's
programmatic creation path (predictive.py), which has no human picking from
a dropdown - the machine name comes from whatever a user's dataset called
it. DowntimeTracking/PaceTracking retrofit to explicit dropdown selection
instead and don't need this - see the design spec's Frontend section."""
from __future__ import annotations

import uuid

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.machine import Machine

FUZZY_MATCH_THRESHOLD = 0.8


def _levenshtein(a: str, b: str) -> int:
    if a == b:
        return 0
    if not a:
        return len(b)
    if not b:
        return len(a)
    prev = list(range(len(b) + 1))
    for i, ca in enumerate(a, start=1):
        curr = [i] + [0] * len(b)
        for j, cb in enumerate(b, start=1):
            cost = 0 if ca == cb else 1
            curr[j] = min(prev[j] + 1, curr[j - 1] + 1, prev[j - 1] + cost)
        prev = curr
    return prev[-1]


def normalized_similarity(a: str, b: str) -> float:
    """1.0 - normalized edit distance, after trim + casefold. 1.0 = identical."""
    na, nb = a.strip().casefold(), b.strip().casefold()
    longest = max(len(na), len(nb))
    if longest == 0:
        return 1.0
    return 1 - (_levenshtein(na, nb) / longest)


async def resolve_or_create_machine(
    db: AsyncSession, org_id: uuid.UUID, raw_name: str, default_work_center_id: uuid.UUID
) -> Machine:
    """Exact match (trim+casefold) on an existing Machine.name -> reuse it.
    Otherwise create a new Machine under default_work_center_id, flagged
    needs_review=True only when it's a fuzzy-close near-duplicate of an
    existing name (a likely typo, worth a human glance); a genuinely novel
    name is created without the flag."""
    existing = (await db.execute(select(Machine).where(Machine.org_id == org_id))).scalars().all()
    target = raw_name.strip()
    for m in existing:
        if m.name.strip().casefold() == target.casefold():
            return m

    needs_review = any(normalized_similarity(target, m.name) >= FUZZY_MATCH_THRESHOLD for m in existing)
    code = target.upper().replace(" ", "-")[:50]
    suffix = 1
    existing_codes = {m.code for m in existing}
    base_code = code
    while code in existing_codes:
        suffix += 1
        code = f"{base_code[:45]}-{suffix}"

    machine = Machine(
        org_id=org_id, work_center_id=default_work_center_id, code=code, name=target, needs_review=needs_review,
    )
    db.add(machine)
    await db.flush()
    return machine
```

"""One-time backfill: turns existing free-text machine/line values on
DowntimeIncident, MaintenanceSchedule, and PaceSession into real registry
rows and FKs. Safe to re-run (idempotent) - already-resolved rows (machine_id
/work_center_id already set) are skipped.

Run: python -m scripts.backfill_machine_registry [--org-id UUID]
(omit --org-id to run across every org)
"""
from __future__ import annotations

import argparse
import asyncio
import uuid

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine

from app.core.config import get_settings
from app.models.downtime_tracking import DowntimeIncident
from app.models.machine import Machine
from app.models.maintenance_schedule import MaintenanceSchedule
from app.models.pace_tracking import PaceSession
from app.models.tenant import Org
from app.models.work_center import WorkCenter
from app.services.registry_matching import FUZZY_MATCH_THRESHOLD, normalized_similarity, resolve_or_create_machine

_UNASSIGNED_CODE = "UNASSIGNED"


async def _get_or_create_unassigned_work_center(db: AsyncSession, org_id: uuid.UUID) -> WorkCenter:
    """Backfilled machines/lines have no known routing step yet - park them
    under one placeholder work center per org rather than guessing a real
    one; an admin re-assigns them via the Machines/WorkCenters UI later."""
    existing = (
        await db.execute(
            select(WorkCenter).where(WorkCenter.org_id == org_id, WorkCenter.code == _UNASSIGNED_CODE)
        )
    ).scalar_one_or_none()
    if existing is not None:
        return existing
    wc = WorkCenter(org_id=org_id, code=_UNASSIGNED_CODE, name="Unassigned (from backfill)")
    db.add(wc)
    await db.flush()
    return wc


def _dedupe_code(base: str, taken: set[str]) -> str:
    code = base.upper().replace(" ", "-")[:50] or "MACHINE"
    candidate = code
    suffix = 1
    while candidate in taken:
        suffix += 1
        candidate = f"{code[:45]}-{suffix}"
    taken.add(candidate)
    return candidate


async def backfill_org(db: AsyncSession, org_id: uuid.UUID) -> dict[str, int]:
    counts = {"merged": 0, "flagged": 0, "created": 0}
    default_wc = await _get_or_create_unassigned_work_center(db, org_id)

    # Snapshot which Machine ids already existed before this run touches
    # anything - resolve_or_create_machine (Task 4) returns a Machine either
    # way, so this snapshot is how we tell "matched an existing row" apart
    # from "just created one" for the counts below.
    pre_existing_ids = {
        m.id for m in (await db.execute(select(Machine).where(Machine.org_id == org_id))).scalars().all()
    }

    async def resolve(raw_name: str) -> Machine:
        machine = await resolve_or_create_machine(db, org_id, raw_name, default_wc.id)
        if machine.id in pre_existing_ids:
            counts["merged"] += 1
        elif machine.needs_review:
            counts["flagged"] += 1
        else:
            counts["created"] += 1
        return machine

    incidents = (
        await db.execute(
            select(DowntimeIncident).where(DowntimeIncident.org_id == org_id, DowntimeIncident.machine_id.is_(None))
        )
    ).scalars().all()
    for incident in incidents:
        incident.machine_id = (await resolve(incident.machine)).id

    schedules = (
        await db.execute(
            select(MaintenanceSchedule).where(
                MaintenanceSchedule.org_id == org_id, MaintenanceSchedule.machine_id.is_(None)
            )
        )
    ).scalars().all()
    for sched in schedules:
        sched.machine_id = (await resolve(sched.machine)).id

    # PaceSession.line maps to WorkCenter, not Machine - same exact-match/
    # fuzzy-flag policy, separate registry.
    work_centers = (await db.execute(select(WorkCenter).where(WorkCenter.org_id == org_id))).scalars().all()
    wc_by_casefold = {w.name.strip().casefold(): w for w in work_centers}
    wc_taken_codes = {w.code for w in work_centers}

    async def resolve_line(raw_line: str) -> WorkCenter:
        nonlocal work_centers
        target = raw_line.strip()
        key = target.casefold()
        if key in wc_by_casefold:
            counts["merged"] += 1
            return wc_by_casefold[key]
        needs_review_line = any(
            normalized_similarity(target, w.name) >= FUZZY_MATCH_THRESHOLD for w in work_centers
        )
        if needs_review_line:
            counts["flagged"] += 1
        else:
            counts["created"] += 1
        code = _dedupe_code(target, wc_taken_codes)
        w = WorkCenter(org_id=org_id, code=code, name=target)
        db.add(w)
        await db.flush()
        work_centers.append(w)
        wc_by_casefold[key] = w
        return w

    sessions = (
        await db.execute(select(PaceSession).where(PaceSession.org_id == org_id, PaceSession.work_center_id.is_(None)))
    ).scalars().all()
    for s in sessions:
        s.work_center_id = (await resolve_line(s.line)).id

    return counts


async def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--org-id", type=str, default=None)
    args = parser.parse_args()

    settings = get_settings()
    engine = create_async_engine(settings.database_url)
    session_factory = async_sessionmaker(engine, expire_on_commit=False)

    async with session_factory() as db:
        if args.org_id:
            org_ids = [uuid.UUID(args.org_id)]
        else:
            org_ids = [row[0] for row in (await db.execute(select(Org.id))).all()]

        totals = {"merged": 0, "flagged": 0, "created": 0}
        for org_id in org_ids:
            counts = await backfill_org(db, org_id)
            for k in totals:
                totals[k] += counts[k]
        await db.commit()
        print(f"Backfill complete: {totals}")


if __name__ == "__main__":
    asyncio.run(main())

      queryClient.invalidateQueries({ queryKey: ["machines"] });
    },
    onError: (e: Error) => setError(e.message),
  });

  const clearReview = useMutation({
    mutationFn: async (id: string) => {
      const res = await apiFetch(`/machines/${id}`, { method: "PATCH", body: JSON.stringify({ needs_review: false }) });
      if (!res.ok) throw new Error("Failed to update machine");
      return res.json();
    },
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ["machines"] }),
  });

  const workCenterName = (id: string) => workCenters.data?.find((w) => w.id === id)?.name ?? id;

  function onSubmit(e: FormEvent) {
    e.preventDefault();
    setError(null);
    if (!workCenterId) {
      setError("Pick a work center first");
      return;
    }
    create.mutate();
  }

  return (
    <div>
      {error && <Alert variant="destructive" className="mb-6">{error}</Alert>}

      <Card className="mb-8">
        <CardHeader>
          <CardTitle>Add a machine</CardTitle>
        </CardHeader>
        <CardContent>
          <form onSubmit={onSubmit} className="grid gap-4 sm:grid-cols-2 lg:grid-cols-4">
            <Field label="Work center" htmlFor="m-wc">
              <Select id="m-wc" value={workCenterId} onChange={(e) => setWorkCenterId(e.target.value)}>
                <option value="">Select…</option>
                {(workCenters.data ?? []).map((wc) => (
                  <option key={wc.id} value={wc.id}>
                    {wc.code} — {wc.name}
                  </option>
                ))}
              </Select>
            </Field>
            <Field label="Code" htmlFor="m-code">
              <Input id="m-code" value={code} onChange={(e) => setCode(e.target.value)} required />
            </Field>
            <Field label="Name" htmlFor="m-name">
              <Input id="m-name" value={name} onChange={(e) => setName(e.target.value)} required />
            </Field>
            <div className="flex items-end">
              <Button type="submit" className="w-full" loading={create.isPending}>
                Add machine
              </Button>
            </div>
          </form>
        </CardContent>
      </Card>

      <label className="mb-3 flex items-center gap-2 text-sm">
        <input type="checkbox" checked={reviewOnly} onChange={(e) => setReviewOnly(e.target.checked)} />
        Needs review only
      </label>

      {machines.data && machines.data.length === 0 ? (
        <EmptyState icon={<Cog />} title="No machines yet" />
      ) : (
        <TableWrap>
          <Table>
            <THead>
              <TR>
                <TH>Code</TH>
                <TH>Name</TH>
                <TH>Work center</TH>
                <TH>Status</TH>
                <TH></TH>
              </TR>
            </THead>
            <TBody>
              {machines.data?.map((m) => (
                <TR key={m.id}>
                  <TD className="font-medium">{m.code}</TD>
                  <TD>{m.name}</TD>
                  <TD>{workCenterName(m.work_center_id)}</TD>
                  <TD>
                    <Badge variant={m.status === "active" ? "success" : "outline"}>{m.status}</Badge>
                    {m.needs_review && (
                      <Badge variant="destructive" className="ml-2">
                        Needs review
                      </Badge>
                    )}
                  </TD>
                  <TD>
                    {m.needs_review && (
                      <Button variant="ghost" size="sm" onClick={() => clearReview.mutate(m.id)}>
                        Mark reviewed
                      </Button>
                    )}
                  </TD>
                </TR>
              ))}
            </TBody>
          </Table>
        </TableWrap>
      )}
    </div>
  );
}

```tsx
// frontend/src/pages/Routings.tsx
import { useState } from "react";
import { Route as RouteIcon } from "lucide-react";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { apiFetch } from "../api/client";
import { Field } from "@/components/Field";
import { EmptyState } from "@/components/EmptyState";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { Badge } from "@/components/ui/badge";
import { Alert } from "@/components/ui/alert";
import { Select } from "@/components/ui/select";
import { Table, TBody, TD, TH, THead, TR, TableWrap } from "@/components/ui/table";

interface ItemOption {
  id: string;
  sku: string;
  name: string;
}

interface WorkCenterOption {
  id: string;
  code: string;
  name: string;
}

interface RoutingStep {
  id: string;
  sequence: number;
  work_center_id: string;
  cycle_time_seconds: number | null;
  setup_time_seconds: number | null;
}

interface RoutingResponse {
  id: string;
  item_id: string;
  version: number;
  status: string;
  steps: RoutingStep[];
}

interface DraftStep {
  work_center_id: string;
  cycle_time_seconds: string;
}

export function RoutingsPanel() {
  const queryClient = useQueryClient();
  const [itemId, setItemId] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [draftSteps, setDraftSteps] = useState<Record<string, DraftStep[]>>({});

  const items = useQuery<ItemOption[]>({
    queryKey: ["items"],
    queryFn: async () => {
      const res = await apiFetch("/items");
      if (!res.ok) throw new Error("Failed to load items");
      return res.json();
    },
  });

  const workCenters = useQuery<WorkCenterOption[]>({
    queryKey: ["work-centers"],
    queryFn: async () => {
      const res = await apiFetch("/work-centers");
      if (!res.ok) throw new Error("Failed to load work centers");
      return res.json();
    },
  });

  const routings = useQuery<RoutingResponse[]>({
    queryKey: ["routings", itemId],
    queryFn: async () => {
      const res = await apiFetch(`/routings?item_id=${itemId}`);
      if (!res.ok) throw new Error("Failed to load routings");
      return res.json();
    },
    enabled: !!itemId,
  });

  const createRouting = useMutation({
    mutationFn: async () => {
      const res = await apiFetch(`/routings?item_id=${itemId}`, { method: "POST" });
      if (!res.ok) {
        const body = await res.json().catch(() => ({}));
        throw new Error(body.detail ?? "Failed to create routing");
      }
      return res.json();
    },
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ["routings", itemId] }),
    onError: (e: Error) => setError(e.message),
  });

  const saveSteps = useMutation({
    mutationFn: async ({ routingId, steps }: { routingId: string; steps: DraftStep[] }) => {
      const body = steps.map((s, i) => ({
        sequence: i + 1,
        work_center_id: s.work_center_id,
        cycle_time_seconds: s.cycle_time_seconds ? Number(s.cycle_time_seconds) : null,
      }));
      const res = await apiFetch(`/routings/${routingId}/steps`, { method: "POST", body: JSON.stringify(body) });
      if (!res.ok) {
        const errBody = await res.json().catch(() => ({}));
        throw new Error(errBody.detail ?? "Failed to save steps");
      }
      return res.json();
    },
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ["routings", itemId] }),
    onError: (e: Error) => setError(e.message),
  });

  const activate = useMutation({
    mutationFn: async (routingId: string) => {
      const res = await apiFetch(`/routings/${routingId}/activate`, { method: "POST" });
      if (!res.ok) {
        const body = await res.json().catch(() => ({}));
        throw new Error(body.detail ?? "Failed to activate routing");
      }
      return res.json();
    },
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ["routings", itemId] }),
    onError: (e: Error) => setError(e.message),
  });

  function stepsFor(routing: RoutingResponse): DraftStep[] {
    return draftSteps[routing.id] ?? routing.steps.map((s) => ({
      work_center_id: s.work_center_id,
      cycle_time_seconds: s.cycle_time_seconds != null ? String(s.cycle_time_seconds) : "",
    }));
  }

  function addStep(routing: RoutingResponse) {
    const current = stepsFor(routing);
    setDraftSteps({ ...draftSteps, [routing.id]: [...current, { work_center_id: "", cycle_time_seconds: "" }] });
  }

  function updateStep(routing: RoutingResponse, index: number, patch: Partial<DraftStep>) {
    const current = [...stepsFor(routing)];
    current[index] = { ...current[index], ...patch };
    setDraftSteps({ ...draftSteps, [routing.id]: current });
  }

  return (
    <div>
      {error && <Alert variant="destructive" className="mb-6">{error}</Alert>}

      <Card className="mb-8">
        <CardHeader>
          <CardTitle>Pick an item</CardTitle>
        </CardHeader>
        <CardContent>
          <div className="flex flex-wrap items-end gap-3">
            <Field label="Item" className="min-w-[16rem]">
              <Select value={itemId} onChange={(e) => setItemId(e.target.value)}>
                <option value="">Select an item…</option>
                {(items.data ?? []).map((i) => (
                  <option key={i.id} value={i.id}>
                    {i.sku} — {i.name}
                  </option>
                ))}
              </Select>
            </Field>
            <Button variant="secondary" disabled={!itemId} loading={createRouting.isPending} onClick={() => createRouting.mutate()}>
              New draft routing
            </Button>
          </div>
        </CardContent>
      </Card>

      {!itemId ? (
        <EmptyState icon={<RouteIcon />} title="Pick an item to see its routings" />
      ) : (
        (routings.data ?? []).map((routing) => (
          <Card key={routing.id} className="mb-6">
            <CardHeader>
              <CardTitle>
                Version {routing.version} — <Badge variant={routing.status === "active" ? "success" : "outline"}>{routing.status}</Badge>
              </CardTitle>
            </CardHeader>
            <CardContent className="space-y-4">
              <TableWrap>
                <Table>
                  <THead>
                    <TR>
                      <TH>#</TH>
                      <TH>Work center</TH>
                      <TH>Cycle time (s)</TH>
                    </TR>
                  </THead>
                  <TBody>
                    {stepsFor(routing).map((s, i) => (
                      <TR key={i}>
                        <TD>{i + 1}</TD>
                        <TD>
                          <Select
                            value={s.work_center_id}
                            onChange={(e) => updateStep(routing, i, { work_center_id: e.target.value })}
                            disabled={routing.status !== "draft"}
                          >
                            <option value="">Select…</option>
                            {(workCenters.data ?? []).map((wc) => (
                              <option key={wc.id} value={wc.id}>
                                {wc.code} — {wc.name}
                              </option>
                            ))}
                          </Select>
                        </TD>
                        <TD>
                          <Input
                            type="number"
                            value={s.cycle_time_seconds}
                            onChange={(e) => updateStep(routing, i, { cycle_time_seconds: e.target.value })}
                            disabled={routing.status !== "draft"}
                          />
                        </TD>
                      </TR>
                    ))}
                  </TBody>
                </Table>
              </TableWrap>

              {routing.status === "draft" && (
                <div className="flex flex-wrap gap-2">
                  <Button variant="outline" size="sm" onClick={() => addStep(routing)}>
                    Add step
                  </Button>
                  <Button
                    size="sm"
                    loading={saveSteps.isPending}
                    onClick={() => saveSteps.mutate({ routingId: routing.id, steps: stepsFor(routing) })}
                  >
                    Save steps
                  </Button>
                  <Button
                    variant="secondary"
                    size="sm"
                    disabled={routing.steps.length === 0}
                    loading={activate.isPending}
                    onClick={() => activate.mutate(routing.id)}
                  >
                    Activate
                  </Button>
                </div>
              )}
            </CardContent>
          </Card>
        ))
      )}
    </div>
  );
}
```
